Schedule → Calendar

Upload a screenshot of your class timetable and get a calendar file you can import into Google Calendar, Apple Calendar, or Outlook.

1 Upload your timetable screenshot

2 Check the courses (fix anything that's wrong)

Course Type Day Period start Period end Week start Week end Location Teacher

3 Term settings

Times are treated as Asia/Shanghai. If your term is in a different timezone, ask whoever built this to adjust it.

4 Get your calendar file

After downloading: in Google Calendar, go to Settings → Import & export → Import, and select the file. On iPhone/Mac, just open the file and it adds itself to Calendar.
